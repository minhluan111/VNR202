# Đường tới Điện Biên Phủ — Frontend

Trải nghiệm học tập tương tác về quá trình đẩy mạnh cuộc kháng chiến đến thắng lợi trong giai đoạn 1951–1954.

Gồm ba trang:

- `#presentation`: nội dung thuyết trình dạng triển lãm số.
- `#quiz`: 8 câu hỏi trắc nghiệm có giải thích và chấm điểm.
- `#game`: game ra quyết định, cân bằng tổ chức, chiến lược và hậu cần.

## Chạy dự án

```bash
npm install
npm run dev
```

Tạo bản production bằng `npm run build`.
